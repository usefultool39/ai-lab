## 1. 这个任务是什么？

**感知机（Perceptron）** 是 1958 年心理学家 Frank Rosenblatt 提出的算法。它是神经网络的"祖宗"——你现在用的 ChatGPT、刷脸解锁、所有深度学习模型，本质上都是感知机的"超级加强版"。

### 一句话解释

感知机就是一个**会自己调参数的"打分裁判"**。你给它一堆样本（带特征 + 标签），它一开始瞎猜，猜错了就改改自己的判断标准，改着改着就学会了。

### 一个生活比喻

想象你是一个水果摊老板，要靠两个特征判断一个水果是**苹果🍎**还是**橘子🍊**：

| 特征 | 苹果 | 橘子 |
|------|------|------|
| 颜色（红→橙） | 偏红 (0.8) | 偏橙 (0.2) |
| 直径（cm） | 大 (0.9) | 小 (0.3) |

感知机的"判断公式"就是：

```
分数 = 颜色权重 × 颜色 + 大小权重 × 大小 + 偏置
如果 分数 > 0 → 苹果 (+1)
否则 → 橘子 (-1)
```

权重一开始是随机的（瞎猜）。每次拿到一个水果：

- **猜对了** → 不动（这组权重没毛病）
- **猜错了** → 调权重（让"苹果的特征"权重变高一点，"橘子的特征"权重变低一点）

几千个水果看完，权重就稳定了——这个水果摊老板**学会了**区分苹果和橘子。

### 数学公式（一行就够了）

$$
\hat{y} = \text{sign}(w \cdot x + b)
$$

各符号：

- $x = (x_1, x_2, \ldots, x_n)$：输入特征向量（比如 [颜色, 大小]）
- $w = (w_1, w_2, \ldots, w_n)$：权重，每个特征的重要性，是"要学出来的东西"
- $b$：偏置，一个常量偏移
- $\text{sign}(z)$：符号函数，$z > 0$ 返回 +1，否则返回 -1
- $\hat{y}$：预测标签，+1 表示一类，-1 表示另一类

**学习规则**：错一次就把 $w$ 往正确方向推一点点。

**几何直觉**：$w \cdot x + b = 0$ 就是 N 维空间里的一个**超平面**，感知机的目标就是找到这个平面把两类点完美切开。

### 它能干什么、不能干什么

| 能 | 不能 |
|------|------|
| **线性可分的二分类**（一条直线能分开苹果和橘子） | **异或（XOR）**——线性分不开的（Minsky 1969 证明了这一点，直接导致 AI 第一次寒冬） |
| 训练极快、代码极简 | 处理复杂模式（图像、语言） |
| 在线学习（来一个样本学一个） | 多分类（除非用一对多策略） |
| 可解释（权重直接告诉你"哪个特征更重要"） | 输出概率（只能硬分类） |

💡 **历史彩蛋**：Rosenblatt 当年吹得太狠（说感知机能"看、说、自我复制"），Minsky 啪啪打脸后 AI 经费砍了 10 年——这就是"AI 寒冬"的由来。

我们这个 Toy 任务就是要在合成的"线性可分"数据上跑通它，感知机能完美学会（这是它的甜区），这样你就能直观感受到"机器学习"四个字到底在干嘛。

## 3. 具体怎么做？（Colab 友好版）

下面是 `train.py` 的完整思路，全 CPU、零依赖（只用 numpy + matplotlib），Colab 默认就装好：

### Step A：生成 toy 数据

```python
import numpy as np

rng = np.random.default_rng(42)
X_pos = rng.normal(loc=[2.0, 2.0], scale=0.55, size=(100, 2))
X_neg = rng.normal(loc=[-2.0, -2.0], scale=0.55, size=(100, 2))
X = np.vstack([X_pos, X_neg])
y = np.array([1] * 100 + [-1] * 100, dtype=float)  # 标签用 {-1,+1}
```

⚠️ **注意**：要用**真正线性可分**的数据。`sklearn.make_classification(class_sep=1.0)` 并不保证可分——实测可能卡在 ~85% 准确率。两类高斯簇拉开均值更稳妥。

### Step B：感知机类（核心算法）

```python
import numpy as np

class Perceptron:
    def __init__(self, lr=1.0, max_epochs=100):
        self.lr = lr
        self.max_epochs = max_epochs

    def fit(self, X, y):
        n_samples, n_features = X.shape
        self.w = np.zeros(n_features)  # 初始化为0（也可以用小随机数）
        self.b = 0.0
        self.errors_history = []

        for epoch in range(self.max_epochs):
            errors = 0
            for xi, yi in zip(X, y):
                pred = np.sign(np.dot(xi, self.w) + self.b)
                if pred != yi:
                    update = self.lr * yi
                    self.w += update * xi
                    self.b += update
                    errors += 1
            self.errors_history.append(errors)
            if errors == 0:   # 全对就提前停
                break
        return self

    def predict(self, X):
        return np.sign(X @ self.w + self.b)
```

💡 **算法名字**：这叫 **PLA（Perceptron Learning Algorithm）**，是最经典的版本。还有 Pocket 算法（保存历史最优解）用来处理线性不可分的情况。

### Step C：训练 + 评估

```python
model = Perceptron(lr=1.0, max_epochs=100)
model.fit(X_train, y_train)
acc = (model.predict(X_test) == y_test).mean()
print(f"测试准确率：{acc:.2%}")
```

⚠️ **常见坑**：
1. 忘了把标签转成 ±1，用 0/1 的话更新公式就错了
2. 学习率太大 → 震荡；太小 → 收敛慢
3. 数据不可分 → 永远不会收敛（所以 max_epochs 必须有）

## 4. 你应该记住的三件事

| 序号 | 知识点 | 为什么重要 |
|------|--------|-----------|
| 1 | **线性可分 → PLA 一定收敛** | 这是有数学证明的！Novikoff 定理说最多错 $\frac{R^2}{\gamma^2}$ 次 |
| 2 | **感知机 ≈ 逻辑回归去掉 sigmoid** | 前者硬分类，后者软输出概率，这俩是近亲 |
| 3 | **"深度"就是多层感知机堆起来** | 输入 → 隐藏层（加激活函数）→ 输出，就是神经网络了 |

## FAQ：你可能想问的

**Q: 为什么权重初始化为 0 就行？别的算法不都要随机初始化吗？**
A: 因为 PLA 是错一个样本就更新一次，只要数据可分，从哪开始都能走到解。神经网络就不行了（对称性问题）。

**Q: 感知机现在还有人用吗？**
A: 学术界基本没人用了，但它的**思想**无处不在——梯度下降、误差修正、在线学习，这些都是从 PLA 来的。

**Q: 下一步学什么？**
A: 把 `sign` 换成 `sigmoid` → **逻辑回归**；加隐藏层 → **MLP（多层感知机）**；这俩是感知机的直系后代。
